   The first owner is created on PocketBase's FIRST HTTP REQUEST (the readiness
   probe triggers it), and the one-time link is printed to the pocketbase
   container's stdout. It is in no other place - copy it now:

     kubectl logs deploy/{{ include "c11n.fullname" . }} -c pocketbase | grep 'c11n bootstrap'

   If the pod has already restarted, use --previous. The link is single use and
   expires after {{ .Values.invite.ttlHours }}h; if it is lost, mint another
   from an owner session (Invite in the overlay) - there is no email channel.

   overlay's sidebar by an owner or team member.
